# FIXSERVICE — демо-сайт автосервиса

Демонстрационный лендинг автосервиса в Ростове-на-Дону для показа владельцам автосервисов.

## Что внутри
- Первый экран с оффером и кнопками записи
- Счётчики: 12 000+ машин, 14 лет, рейтинг 4.9
- Услуги с ценами «от» и кнопкой заявки (предвыбирает услугу в квизе)
- «О нас» и преимущества 01–06 в духе «делаем на совесть»
- Кейсы-аккордеон с фото машин
- Этапы работы и отзывы
- Квиз-воронка из 4 шагов: услуга → авто → время → контакты
- Контакты, адаптив под телефон, липкая кнопка записи на мобильных

## Запуск
Откройте `index.html` в браузере — сборка не нужна.

## Заявки
Сейчас квиз работает в демо-режиме: данные выводятся в консоль браузера (`js/main.js`, функция `submitQuiz`).
Для боевого сайта туда подключается Telegram-бот, CRM или почта.
